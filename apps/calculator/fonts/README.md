# Doto

Unmodified Google Fonts variable font, by Óliver Lalan / The Doto Project
Authors. Licensed under the SIL Open Font License 1.1 in `OFL.txt`, which is
also embedded beside the font in Calculator's resources.

- Source: https://github.com/google/fonts/tree/main/ofl/doto
- Upstream: https://github.com/oliverlalan/Doto
- Original filename: `Doto[ROND,wght].ttf`
- Source Git blob: `ed8f0db9fb890c570b558941201d1504483f5ebc`
- Axes: `wght` 100–900; `ROND` 0–100 (default 0, square dots).

Only Calculator's expression (Regular, 16 px) and main result (Bold, 52 px)
use Doto. Both sizes follow the kit's text scaling. Controls and history
retain their existing fonts.
